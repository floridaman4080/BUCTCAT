# 重生之我在北化当校猫

> 基于Unity开发的2D像素风格横板RPG北京化工大学校史馆游戏项目

## 游戏介绍

穿越时空，你将化身一只拥有特殊使命的小猫！踏入1958年北京化工大学的建校元年。从一片荒芜到梦想启航，你将以“猫咪视角”漫步于初建的校园，亲历第一批师生艰苦创业的燃情岁月。收集历史碎片，解锁珍贵档案，成为北化历史的独家见证者。一起喵看校史，探索北化精神的起源吧！

## 键位操作

电脑端：A D控制左右移动 Space跳跃 S+Space下跳<br>
移动端：摇杆左右移动控制左右移动 右边方块键跳跃 摇杆向下移动+右边方块键下跳

## 技术实现（bushi

基于树类的可视化node节点对话系统<br>
视差移动<br>
单项平台的实现<br>
对不同比例的屏幕的适配<br>
复杂动作逻辑控制<br>
道具系统
